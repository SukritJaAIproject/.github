# Support

Thanks for using these projects. Here is where to go for help.

- **Something is broken?** Open an issue with the bug-report form in the repository concerned.
- **Have a question or an idea?** Use GitHub Discussions where the repository has them enabled, otherwise open an issue with the `question` label.
- **Security problem?** Do not open a public issue; follow `SECURITY.md`.
- **EV-charger or OCPP interoperability questions** (DIN 70121, ISO 15118, OCPP 1.6-J) are welcome in the `EV_Charger_Fault_Detection_AI` and `bpc-csms-cloud` repositories.
- **Local LLM workbench questions** belong in `Qwen-Local-AI-Workbench`.

Questions in Thai or English are both fine. Replies normally come within a week; the maintainer works on these projects alongside a full-time role, so patience is appreciated.
